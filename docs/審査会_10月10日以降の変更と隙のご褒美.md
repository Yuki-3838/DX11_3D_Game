## 2. 隙を突いた時のご褒美 — どう実現したか(自分なりの考え)

### 2-1. 何を「ご褒美」にしたか、何をしなかったか

**しなかったこと(と理由)**

- **パリィは入れない**: 防御は回避だけ。「受け止めるタイミングを当てる」遊びにすると、敵の攻撃の形を読む意味が薄れる。
- **「PERFECT」「CHANCE」の表示・回避成功のスローは使わない**: 以前は隙のときにロックオンの枠を緑にし「CHANCE」と出していたが、**答えを画面が先に言ってしまう**のでやめた。敵の体を見て判断してほしい。
- **隙への一撃のダメージは増やしていない**: ダメージを上げると「隙を待つのが一番効率がいい」という単なる数字の話になり、作業になりやすい。

**したこと**: ご褒美を **「体で分かる」→「敵が止まる」→「次の攻撃のチャンスになる」** の3段で返す。

### 2-2. 1段目: 隙に入れた一撃は手応えが重い

敵が攻撃の後の硬直(隙)にいる間に当てると、命中の手応えを **1.4倍** にする。

| | 通常の弱攻撃 | 隙への弱攻撃 | 隙への強攻撃 |
|---|---|---|---|
| ヒットストップ | 0.05秒 | 0.07秒 | 0.105秒 |
| 画面の揺れ | 1.1 | 1.54 | 2.31 |
| 火花の大きさ | 1倍 | 1.4倍 | 2.1倍 |

(強攻撃は1.5倍、隙は1.4倍で掛け算。ヒットストップは0.12秒で頭打ち)

「読みが当たった」が数字ではなく**手と目に伝わる**ようにした。

### 2-3. 2段目: 隙に入れると敵が怯みやすい(怯み値2倍)

攻撃ごとに「怯み値」を敵に溜め、しきい値を超えると敵が **0.9秒怯む**。隙に入れた攻撃は怯み値が **2倍** になる。

| | 通常 | 隙へ |
|---|---|---|
| 弱攻撃 | 14 | 28 |
| 強攻撃 | 34 | 68 |

- 最初のしきい値は150。隙に強攻撃1発(68)+弱3段(84)= 152 で届く計算。**1回の隙をしっかり突けば最初の怯みが取れる**。
- 怯むと敵は打たれた側と反対へ顔を背けてのけぞり、**構えていた攻撃も取り消される**。怯み中は向き直らないので、**背後へ回り込むチャンス**にもなる。
- 怯ませた瞬間は通常の命中よりさらに強く止め(0.12秒)・揺らす。

### 2-4. 一方的にならないための歯止め

ご褒美が強すぎると、敵が何もできないまま殴られ続けて、読み合いが消える。

- **怯むたびにしきい値が1.25倍**(150 → 188 → 234 → 293 → 366 → 375で上限)。モンハンの怯み耐性と同じ考え方。1戦で8回前後に収まる。
- **怯み中は重ねて怯まない**。
- **当てない時間が続くと怯み値は毎秒6ずつ抜ける**。適当に殴っていたらいつの間にか怯んだ、を防ぐ。
- **怒り中は怯みにくい(1.5倍)**。

### 2-5. 10月10日以降に足したこと: 隙を「作る場面」を増やした

ご褒美があっても、隙が「敵の攻撃が終わるのを離れて待つ」だけだと作業になる。そこで隙の種類を増やした。

- **突進を壁にぶつけさせる** → よろめきで隙が 1.1秒 → 2.2秒。自分の位置取りで大きな隙を作れる。
- **向き直りに時間がかかる** → 敵の横や後ろに回ると、振り向くまでの間に殴れる。ただし背後には2回に1回尾回転が来るので、「後ろにいれば安全」にはならない。
- **弱るほど隙が長い**(体力50%以下で1.2倍、20%以下で1.5倍)。終盤ほど「効いている」ことが隙の長さで伝わる。

### 2-6. 10月10日以降に足したこと: 「押したのに出ない」を潰した

隙のご褒美を作る以前に、**隙を見て押した攻撃が出ないと、プレイヤーは「回避中に見えた隙は突けない」と誤って学ぶ**。

- 原因: 回避は0.5秒、押した攻撃を覚えておくのは0.3秒。回避の前半に押すと、回避が終わる前に忘れていた。
- 修正: **回避中に押した攻撃は、回避が終わるまで期限を減らさない**。待つのは最長でも回避の長さ(約0.5秒)なので、忘れた頃に勝手に殴ることはない。
- 確かめ方: 回避を押してから 0.05〜0.55秒後に攻撃を1回だけ押す試行を自動で10回。

  | | 攻撃が出た回数 |
  |---|---|
  | 修正前 | 6 / 10(0.05〜0.20秒に押した4回が消えた) |
  | 修正後 | **10 / 10** |

### 2-7. まだできていないこと(聞かれたら正直に)

- 「敵の攻撃が来たら離れ、終わったら戻って殴る」という**ヒット＆アウェイの繰り返しで勝ててしまう**問題は、まだ解決しきれていない。
- 次にやりたいのは、**攻撃ごとに「近くに残って反撃できる場所」を変える**こと。例えば叩き付けを横へ避ければ、頭が自分の横に落ちてきて、すぐ一撃入れられる。離れて戻るより早く反撃できるようにする。
- そのための記録の仕組み(戦闘の出来事を1行ずつ残すCSV)は作ってあり、今の戦い方を数字で比べられる状態にした。

## 3. 技術の話(聞かれたら)

### 3-1. 隙の判定と、ご褒美の流れ

- 敵の攻撃は「予兆 → 判定 → 隙」の3段階。秒数は**アニメーションと戦闘判定が同じ表**(`Combat::EnemyAttackClip`)から引くので、見た目の振り下ろしと当たる瞬間、隙の始まりがずれない。
- 命中した瞬間(`GameScene` の命中処理)に、敵が隙の状態(`enemy::isInRecovery()`)かを見て、
  手応えの倍率(1.4倍)と怯み値の倍率(`PUNISH_POSTURE_MULTIPLIER = 2.0`)を掛ける。
- 怯み値が超えたら、敵のAIを怯みへ移し、**戦闘判定の側の攻撃も取り消す**(AIだけ怯ませると、のけぞっている敵からダメージが飛んでくるため)。
- 調整値はすべて `CombatAttackTable.h` の1か所に集めてある。デバッグ表示で怯み値のバーを見ながら調整した。

### 3-2. 確かめ方の工夫

- **ゲーム自身が画面をPNGで保存**し、同時に敵の状態・位置・距離などを毎フレームCSVに書く。静止画と数値で確認できる。
- **戦闘記録**(`combat_log`): 攻撃を押した、回避した、敵の攻撃が当たった/前転の無敵で避けた/射程外だった、などを出来事ごとに1行。
- **入力の自動試行**(`input_probe`): 上の「回避中の攻撃」の10回の試行はこれ。修正前後を同じ条件で比べられる。

### 3-3. ほかの技術的な見どころ

| テーマ | 一言 |
|---|---|
| 裏スレッドでの読み込み | 描画文脈(DirectXのデバイスコンテキスト)に触る処理と触らない処理に分け、触らない方だけ裏へ。飛来の場面を流しながら読む |
| シェーダーのキャッシュ | コンパイル結果をファイルに保存。shaderフォルダの更新時刻を鍵にして、書き換えたら作り直す |
| モーションブラー | キャラクターだけ速度バッファへ描き直し、タイルごとの最大速度から集める範囲を決める。カメラの動きは速度から除く |
| スキニング | 線形(LBS)と双対クォータニオン(DQS)のハイブリッド。翼を2.6倍にする場面のため、骨ごとに拡大を分離してから回転を取り出す |
| 壁で滑る移動 | 一度全部動かし、めり込んだ壁ごとに法線方向へ押し戻す(最大4回) |
| モデルの表 | 骨の名前・大きさ・クリップをモデルごとの表に分け、ゲーム側は「首」「尾」などの役割で引く。Wyvernと旧ドラゴンを切り替えられる |
| モーションの移し替え | 前のモデル(Mixamo)の動きを騎士の骨格へ。骨ごとに休止姿勢の向きの差をそろえて重ねる |

## 4. 聞かれそうなことと答え

**Q. 隙に入れたらダメージを増やせばいいのでは?**
A. ダメージを上げると「隙だけ待つのが最適」という数字の話になり、作業になりやすい。手応えと怯み(敵が止まる)で返し、怯みはさらに次の攻撃のチャンスにつながる形にした。

**Q. 成功したと分かる表示は無いの?**
A. 以前は「CHANCE」と出していたが、答えを画面が言ってしまうのでやめた。ヒットストップ・揺れ・火花が強くなること、敵がのけぞることで伝えている。

**Q. 怯みばかりで一方的にならない?**
A. 怯むたびにしきい値が上がる(怯み耐性)、怯み中は重ねて怯まない、時間で抜ける、怒り中は怯みにくい、の4つで抑えている。1戦で8回前後。

**Q. 回避中の攻撃の修正は、なぜ大事?**
A. 隙を見て押したのに攻撃が出ないと、プレイヤーは「回避中は攻撃できない」と間違って覚える。ご褒美を設計する前に、まず押した入力が必ず届くことを、自動の試行で10回中10回出ることまで確かめた。

**Q. まだ足りないところは?**
A. ヒット＆アウェイの繰り返しで勝てる点。攻撃ごとに「近くに残ったほうが早く反撃できる場所」を作るのが次の課題で、比べるための記録の仕組みは用意してある。
